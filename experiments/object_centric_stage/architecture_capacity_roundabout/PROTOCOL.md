# 环岛稳定 ID 跨场景复现实验协议

状态：正式数据、模型训练、统计分析和质量核查均已完成；跨场景复现判定为`PASS_STABLE_ID_CROSS_SCENE_REPLICATION`。

## 研究问题

在独立的`roundabout-v0`场景中，episode内稳定车辆ID的集合编码器是否继续优于距离排序GRU？本实验对应合流容量匹配实验之后的`GO_STABLE_ID_ONLY`跨场景门槛。

## 跨场景判定

只有同时满足以下条件，才判定稳定ID性能收益得到跨场景复现：

1. 两档容量的`row - set`平均配对差均大于0；
2. 合并两档容量后的episode级配对95%置信区间下界大于0；
3. 动作、持续时间和效应强度分层不存在明显的系统性方向反转；
4. 打乱事实后缀相对同episode事实后缀明显变差。

若未通过，稳定ID仍作为身份一致性的必要设计，但不得表述为跨场景性能创新。

## 长任务及恢复

正式采集与正式训练均由用户手动启动。采集每20条显示纯文本进度、每100条保存断点；训练每5个epoch显示进度，每个条件×种子完成后保存可恢复记录。

采集恢复使用同一配置加`--resume`。训练恢复同样使用`--resume`；只有配置、数据SHA-256和运行元数据完全一致的已完成种子才会跳过。
