# 环岛稳定 ID 复现实验质量核查

总体判定：**PASS**。

## 数据与协议

- 正式数据：2,000个有效episode pair；训练/验证/测试为1,400/300/300。
- 动作×持续时间：10个分层，每层200条；测试集每类动作60条、每种持续时间150条。
- episode seed：2,000个且全部唯一。
- 共同前缀、确定性重放和自车跨表示坐标最大差均为0。
- 数据SHA-256：`7E50BF4A17F55D6666549D7743B1D2E5924F5DFA10411F94BD62431146DE8672`
- 配置SHA-256：`2272811E58C89FC6F255C1BFB6F080DFE472BD8B483EDBA7B9EEF79A8540E92C`

## 训练产物

- 6个条件×5个种子，共30个模型检查点。
- 30份训练记录、30份种子预测和30份完成元数据全部存在。
- 每份元数据签名均与正式配置和数据哈希重新计算结果一致。
- 每份训练记录长度、最佳epoch、最佳验证误差和参数量均与汇总报告一致。
- 标准化种子预测还原为米制后，与汇总预测逐元素最大差为0。
- 所有预测有限；设备记录为CUDA；测试独立单位为300个episode。
- 报告SHA-256：`1F2E22105268E2B55F3DC6526AB767B18071C14BE6C29330EC16D24D6EA74D0D`
- 汇总预测SHA-256：`42AE1A96A6DE2AD2F15ECABC385B9937287F37026C826E4829D088AF9A1D46C0`

## 统计核查

- 两档容量分别按300个测试episode进行10,000次配对Bootstrap。
- 合并分析先对每个episode的两档容量误差取平均，再进行10,000次配对Bootstrap。
- 65k和83k的稳定ID主比较置信区间下界均大于0。
- 两档打乱后缀负对照置信区间下界均大于0。
- 动作、持续时间和效应强度分层的平均差均未出现负向反转，但多个较小分层置信区间跨0，因此只解释为异质性，不解释为每一分层都显著改善。

## 需要公开的边界

- 83k的seed 33出现-0.0480 m轻微反转，不能声称所有训练种子都获益。
- 打乱后缀83k的seed 22误差较高，负对照存在训练种子异质性；65k负对照也独立通过，因此总体负对照不完全依赖该异常种子。
- 部分集合运行的最佳验证epoch接近200轮上限，应公开预算敏感性，但不在看到结果后追加预算。
- 当前指标为`effect-FDE@20`，不是论文最终计划中的更长时域指标。
- 全部证据仍来自Highway-env，尚未跨模拟器验证。
