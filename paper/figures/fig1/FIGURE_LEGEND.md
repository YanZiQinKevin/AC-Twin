# Fig. 3 Legend

**Fig. 3 | Response-conditioned value of same-event suffix encoding.** **a,** Schematic bins use frozen thresholds: zero tolerance 0.0001 m, t1 ≈ 0.2484 m and t2 ≈ 1.8990 m; widths do not encode response magnitude. Episode counts overlap. **b,** Agent–time-weighted position errors from separately trained, same-architecture models. All reconstruct positions using the same event's factual trajectory; suffix encoding differs. **c,** Event-specific value compares same-event and shuffled errors; negative values indicate higher same-event error. The low-response interval crosses zero. **d,** Three prespecified contrasts with the 0.05 materiality line. Positive-all pools all positive-response units. Intervals in c,d use 10,000 whole-episode paired bootstrap resamples of 1,200 episodes. Points are discrete state estimates, not a fitted response curve. Definitions and values are in Sections 3.2 and 4.1.
