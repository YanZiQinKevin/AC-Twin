# Table 8: Supervised controls and feature ablations

Development evidence from the same 1,500 complete ten-action groups. Five primary AURC-regret and five secondary Regret@80 comparisons form separate families, each using 99% intervals for nominal 95% Bonferroni family coverage. All ten intervals, including zero-crossing and negative estimates, are retained. Equal nominal parameters do not imply equal effective capacity.
